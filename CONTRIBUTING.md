# Contributing to encryption

## First things first

Thank you for considering contributing to this project! Before you start, please take a moment to review the
following guidelines to ensure a smooth contribution process. We created this guide to keep this project
clean and organized, so please follow it.

## Contributing:

First, create an issue:

This can be done using the premade Issue templates, or creating a new one

Then, start a pull request and create a new branch for your changes.

Once you're done, add a comment to the PR, and we'll take a look at your code before merging it.

Thanks for helping keep encryption secure and efficient!
